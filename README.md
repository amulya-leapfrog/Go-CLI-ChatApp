### 1. Clone the repo to your local machine and open it in your code editor.

### 2. Run 'docker-compose up' to install the MongoDB server.

### 3. Connect your DB client to the MongoDB server.

### 4. Create a .env file by referencing .env.example.

### 5. Run the 'go run main.go register' command in the terminal to register user; 'go run main.go login' to login the registered user; 'go run main.go history' to see chat history.
